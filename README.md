# Ejecución del Proyecto

`Paso 1:` Clean and Build a nivel raíz.

`Paso 2:` ### Servidor
```bash
java -jar servidor-assembler/target/servidor.jar
```

`Paso 3:` ### Cliente 1
```bash
java -jar cliente-assembler/target/cliente.jar
```

`Paso 4:` ### Cliente 2
```bash
java -jar cliente-assembler\target\cliente.jar 6001
```
